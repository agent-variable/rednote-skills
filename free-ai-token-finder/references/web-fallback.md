## Python 工具不可用时

本机缺少脚本、来源清单、Python 3.10+ 或终端执行能力时，使用助手自带的联网搜索和网页阅读。可读到来源清单时优先检查相关厂商。只有单文件 Skill 时，从随附目录的官方链接出发，也可按用途、地区和福利类型搜索新的厂商官方页面。公开的目录链接和快照可作线索，当前权益以本次打开的官方文件为准。

- 按用户范围搜索厂商定价、免费层、开发文档及活动公告。综合盘点未指定地区时分查中国大陆站和国际站，同时覆盖文本和代码、图像和视频、语音和音频、文档解析、向量与重排。只有网页阅读能力时，核验可访问的官方链接，并说明搜索覆盖范围。
- 打开原页核对，保留接入方式、原始额度单位、地区和资格、领取入口、刷新或截止时间、超额行为、核验日期和官方链接。明确要求无需预充值或超额即停时，只列有对应官方依据的条目。不能核实的权益列为待核验。从账户或客户端才能确认的条件注明核对位置。
- 标明本次结果来自「助手联网核验」，并写清查了哪些范围。遇到同一活动的多条报道，只保留一条权益。若同时缺少联网能力，提供最后一份有日期的目录或已知官方入口，并把当前是否可用标为待核验。
